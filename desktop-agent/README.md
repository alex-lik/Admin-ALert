# Admin-ALert Desktop Agent

Небольшой агент для десктопа админа — сценарий «диск закончился, а человек за этой
машиной ещё не ушёл спать». Если на десктопе не подтвердили алерт за N минут, агент
сообщает серверу, а тот включает эскалацию на телефон.

**Статус: каркас.** Выбор технологии — задача 3.24.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Python + PySide6 / tkinter | быстрый старт, нет сборки, легко тестировать | менее «родное» окно |
| Tauri (Rust + web) | маленький бинарь, нативные always-on-top | требует Rust-тулчейна |
| Electron | всегда-on-top и fullscreen из коробки | тяжёлый (150+ МБ) |

Критерий выбора — размер дистрибутива и надёжность always-on-top окна:
приложение ставится на несколько машин, а не на одну.

## Требования (раздел 3 плана)

- [ ] Окно поверх всех окон, нельзя закрыть без подтверждения
- [ ] Зацикленный сигнал с принудительной громкостью
- [ ] Локальная проверка свободного места на диске
- [ ] Отправка события на сервер в общем формате (`docs/api/events.md`)
- [ ] Таймаут без ack → сообщение серверу, чтобы включилась телефонная эскалация
- [ ] Автозапуск при входе в систему
