# ADR — Architecture Decision Records

Формат: один файл на решение, имя `NNNN-короткое-решение.md`.
Записывается в момент принятия, не переписывается задним числом — если решение
поменялось, добавляется новый ADR со ссылкой на предыдущий.

## Решения

| # | Решение | Статус | Задача |
|---|---|---|---|
| — | Стек сервера: FastAPI или Django | не принято | 1.3 |
| — | Слой звонков: Asterisk AMI или HTTP API | не принято | 1.12 |
| — | Технология desktop-агента | не принято | 3.24 |

## Шаблон

```markdown
# ADR-0001: <Решение>

- **Дата:** YYYY-MM-DD
- **Статус:** предложено / принято / отменено
- **Задача:** 1.3

## Контекст

Что заставляет нас выбирать. Ограничения, бюджет, сроки.

## Решение

Что выбрали.

## Альтернативы

- **Вариант A** — почему не взяли.
- **Вариант B** — почему не взяли.

## Последствия

Что становится проще, что сложнее, что придётся пересмотреть позже.
```
